第 5 章

⚡ 对称加密 - 现代密码学

加密解密用同一把钥匙，速度快到飞起！

🔄 XOR 异或运算

现代加密的基石！规则很简单：

0 XOR 0 = 0
0 XOR 1 = 1
1 XOR 0 = 1
1 XOR 1 = 0

💡 神奇之处：加密用一次密钥，解密再用一次同一个密钥！

🎨 简单比喻

就像用同一张底片：

拍摄 → 得到负片（加密）

再拍摄 → 还原照片（解密）

🗝️ RSA - 公钥密码革命

让互联网安全成为可能的伟大发明！

💡 为什么需要它？

对称加密需要双方先共享密钥，但怎么安全地告诉对方密钥呢？

这就像你和朋友想写信保密，但你们连见面交换暗号都做不到...

📬 锁盒比喻

  1. 你给朋友送一个敞口的锁盒（公钥）
  2. 朋友把信放进去，用盒子上的锁锁住
  3. 朋友把锁好的盒子寄回给你
  4. 只有你有钥匙（私钥），能打开！

乘积：n = 61 × 53 = 3233

这给你，很难反推 p 和 q！
